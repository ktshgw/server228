АДМИН-ПАНЕЛЬ — ОЧЕНЬ КОРОТКАЯ ПАМЯТКА

1. Дважды нажми START_SERVER.bat и дождись слова Done.
2. Дважды нажми OPEN_ADMIN_PANEL.bat.
3. Войди под локальным аккаунтом osu!lazer, которому выданы права Owner.
   Сейчас это аккаунт mindblock.
4. Открой «Пользователи», выбери свой аккаунт и поменяй страну CN на нужную.
5. В «Карты» можно назначать локальный Ranked/Loved всему набору или одной сложности.

ГДЕ ЛЕЖАТ АККАУНТЫ

Аккаунты, пароли, роли и статистика хранятся не в обычном текстовом файле,
а в базе MySQL внутри постоянного Docker-тома server_mysql_data.
Пароли хранятся только в виде хеша. Редактировать пользователей нужно через
админ-панель, а не напрямую в таблицах.

Обычный STOP_SERVER.bat и перезапуск компьютера данные не удаляют.
НИКОГДА не запускай «docker compose down -v» и не удаляй Docker volumes через
«volume prune»: ключ -v / очистка томов удалит базу аккаунтов.

ПОЧЕМУ БЫЛ КИТАЙСКИЙ ФЛАГ

Регистрация пришла с внутреннего Tailscale-IP, для которого GeoIP не знает страну.
Старая запасная настройка ошибочно ставила CN. Теперь новым аккаунтам в таком
случае ставится XX (страна не определена), а любой существующий флаг меняется
через страницу пользователя в админ-панели.
