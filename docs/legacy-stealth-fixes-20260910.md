# Stealth и Legacy — 10.09.2026

Клиент: osu!lazer 2026.804.2, osu.Framework 2026.731.0. Модуль `SomsLegacyStealthFix4`.

## Изменения

- Аватарки хранят исходного пользователя SOMS. Stealth подменяет только изображение; числовые ID официальных игроков не смешиваются с ID сервера. Нажатие на собственный профиль в Stealth открывает официальный профиль выбранного игрока через отдельную внутриигровую панель.
- Загрузка картинки больше не блокирует загрузку карточки или профиля. Сначала появляется встроенная заглушка, затем картинка. Одновременно выполняются максимум четыре загрузки на выделенных потоках: `TextureStore` использует `WaitSafely` при совпадающих запросах и запрещает ожидание на потоках TPL. Ни `Task.Run(Get)`, ни штатный `GetAsync` не устраняют это ограничение.
- Смена личности и выключение Stealth сбрасывают старое изображение; поздние ответы предыдущей загрузки отбрасываются. Изменение PP не перезагружает неизменившуюся аватарку. Ошибки изображения записываются в runtime.log и не прерывают открытие профиля.
- Открытие официального профиля объединяет повторные вызовы загрузки от показа панели и её анимации. Смена пользователя отменяет устаревший запрос.
- Legacy больше не пересоздаёт заголовок и список карт при каждом изменении модов. Обновляются характеристики; запрос таблицы рекордов нужен только при включённом фильтре по модам и объединяется с соседними переключениями.
- Звёзды в заголовке и видимых строках берутся из `BeatmapDifficultyCache` с текущими модами и их настройками. AR/OD/CS/HP показываются через штатные атрибуты ruleset; BPM и длительность учитывают скорость.
- Плитки модов сохраняются при переключениях. Недоступные варианты остаются запрещёнными; семейства DT/NC, SD/PF и пользовательские хоткеи сохраняют поведение.
- Обновления скина объединяются с задержкой 120 мс. Скрытые экраны обновляются при показе. Переключение самого Legacy сохраняет немедленное восстановление штатных элементов.
- Индекс групп и количество сложностей строятся один раз на новый результат фильтрации. Прокрутка папок не пересчитывает всю библиотеку. Готовый результат штатного фильтра подхватывается с интервалом 16 мс вместо 100 мс.
- Зажатая ПКМ быстро перемещает список по позиции мыши, не меняя выбранную карту. ЛКМ и колесо сохраняют независимую прокрутку; Alt+колесо меняет громкость.
