# Legacy: последняя сложность при переходе между мапсетами

Модуль `SomsLegacyLastDiff`, osu!lazer 2026.804.2.
SHA-256: `2891b3f7da89e5754fe6b93fda3741748c581f453edc1b91f6099ba10b804c2a`.

`SomsLegacySongSelect.moveSet()` при переходе стрелками ←/→ выбирает последнюю
доступную сложность соседнего мапсета в порядке списка. Учитываются текущий
фильтр и выбранная группа. ↑/↓ продолжают переключать отдельные сложности.

Сборка модуля прошла без ошибок и предупреждений. Интеграционная проверка
на установленном клиенте подтверждает выбор последней сложности при переходе
вправо и возврате влево, переходы ↑/↓, F1/F3, Shift+F2, независимую прокрутку
колесом и перетаскиванием, миниатюры, игровой цикл и восстановление интерфейса.
Лог: `.test-tmp/legacy-last-diff-integration.log`.

Обновление опубликовано через `switcher/stage-client-release.ps1`.
Оба лаунчера, публичный манифест и повторно скачанный модуль имеют указанный
SHA-256. Предыдущий модуль сохранён в
`.test-tmp/legacy-last-diff-release/previous.dll`.
