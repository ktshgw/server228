# Профили мапперов и категории хоткеев

Клиент: osu!lazer 2026.804.2, SOMS!, 9 сентября 2026.

## Хоткеи

В панели клавиш четыре раздела модов: osu!, osu!taiko, osu!catch, osu!mania.
Внутри используются категории установленного ruleset: упрощающие, усложняющие,
преобразующие, автоматизация, развлекательные и системные. Пустые категории не выводятся.

Назначения хранятся в RealmKeyBinding с RulesetName=soms-mod-hotkeys и Variant=OnlineID режима.
Предыдущие общие назначения (Variant=null) копируются только для отсутствующих записей режима.
Их оригиналы сохраняются. Очистка назначения режима восстанавливает встроенный хоткей,
не подхватывая прежний общий override. Идентификаторы действий по-прежнему зависят от акронима,
поэтому порядок категорий и появление новых модов не сдвигают сохранённые клавиши.

## Профили

Официальные авторы открываются в отдельном нативном UserProfileOverlay. Его дочерние разделы
и переключатель режима используют изолированный API provider. Локальный профиль SOMS!
и его dependency остаются отдельными. Источник пользователя привязан к объекту, а не к ID.

Ссылки подключены в AuthorInfo страницы карты, в обоих блоках автора выбора песни и в
Legacy interface. Автор из локальных метаданных преобразуется в отдельный APIUser:
служебные ID 0/1 заменяются поиском по имени. Realm не изменяется.

Окно отображает официальные аватар, статистику, скоры и карты. Кнопки личных сообщений
и модерации SOMS! исключены из официального профиля; подписчики доступны как счётчик.
Ссылки на официальный сайт и профили сохраняют официальный источник.
Ошибка основного запроса завершает загрузку и показывает «Повторить»; старые ответы
игнорируются после смены профиля, закрытия или уничтожения окна.

Сервер: GET /api/private/official-profiles/users/{user}/{resource}.
Разрешён только фиксированный набор публичных ресурсов профиля; URL назначения всегда osu.ppy.sh.
Используется существующий server-side fetcher, public OAuth scope и формат API 20260804.
Токен клиента SOMS! не пересылается на osu!. Ответы кешируются на 5 минут.
Общий timeout загрузки из источника — 18 секунд, клиентский — 20 секунд.

Документация формата API: https://osu.ppy.sh/docs/index.html#api-versions

- Сервер: 5 тестов official_profiles, Ruff.
- Работающий сервер: профиль по ID и нику, список карт, скоры, последние события;
  повторный ответ из кеша; неподдерживаемый ресурс 404, POST 405.
- Нативный клиент с отдельной тестовой Realm: профиль из реального публичного JSON,
  переключение osu!/taiko, ошибка и повторная загрузка, изоляция социальных действий.
- Фактический клик на автора в нативном выборе песни: автор с ID=1 успешно находится
  по нику. Отдельное окно также обходит запрет native ShowUser на неизвестный ID=0.
- Полный сценарий меню → выбор песни → профиль маппера → моды → реплей → результат →
  повтор → отключение Legacy interface завершён без исключений.
- 141 строка модов, перенос старого Ctrl+D во все режимы, независимое очищение taiko,
  стандартные клавиши и сочетания всех четырёх режимов, 20 повторных инициализаций панели.
- FullPatchLifecycle: 84 регистрации без дубликатов после последовательных и параллельных
  конструкторов. ReplayAvatar: 18 проверок идентификации и аватарок.
