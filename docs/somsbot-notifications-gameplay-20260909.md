# SOMSBot, уведомления и настройки клиента

Обновление SOMS! от 9 сентября 2026 года. Клиент osu!lazer 2026.804.2.

## Чат и сайт

- При подключении к серверу автоматически добавляется вкладка `#announce`.
  Оверлей чата не открывается; канал доступен по F8. Писать в него может SOMSBot.
- Бот сообщает о новом первом месте в общем топе карты по режиму игры.
  Сравнение соответствует серверному рейтингу по очкам. Указаны карта, режим,
  моды, точность и pp; в конце сообщения стоит ник прежнего лидера для штатного
  упоминания в клиенте. Улучшение собственного #1 не создаёт ложную потерю места.
- Новые официальные Ranked-карты проверяются каждые пять минут. Локальная выдача
  Ranked также создаёт объявление. Каталог до включения функции не публикуется
  задним числом. Источник — официальный `beatmapsets/search`, `ranked_desc`.
- Колокольчик справа в шапке сайта показывает потерю #1 и добавление в друзья.
  Получатель должен иметь действующий supporter. Добавление работает с сайта
  и из клиента; повторный запрос той же дружбы не создаёт дубль.
- Настройки аккаунта → «Уведомления»: два независимых переключателя, по умолчанию
  включены. Эти настройки управляют личными уведомлениями сайта. Объявления в
  общем канале доступны всем.
- Есть отметка прочтения, «Прочитать все» и загрузка более ранних уведомлений.
  Запросы изменения защищены сессией и CSRF, чужие уведомления недоступны.

События фиксируются в транзакции обработки скора/дружбы. Таблица `soms_activity`
хранит личные уведомления и очередь сообщений бота. Доставка повторяется после
сбоя с тем же ID сообщения, не создавая новые записи истории. Миграция
`9c6382d59251` добавляет только эту таблицу и её индексы; остальные таблицы
миграция не изменяет. Проверена генерация SQL и применение на текущей БД.

## Настройки игры

- Интерфейс → выбор карт → **pp за карту**: оценки FC на 95%, 98%, 99%, 100%
  справа в заголовке выбранной карты. Используется нативный калькулятор,
  выбранный режим и актуальные настройки модов, включая нестандартную скорость.
  Это оценка: итог зависит также от комбо и распределения попаданий.
  Для неранкед-модов выводится 0; если калькулятор недоступен — прочерк.
- Режим игры → osu! → **Force smooth cursor trail**: непрерывный шлейф даже
  у скинов без `cursormiddle.png`.
- Там же **Sudden death restart on miss**: штатный автоматический перезапуск
  при провале с SD в одиночной osu!-игре.
- Скин → **Draw followpoints**, по умолчанию включено. Выключение скрывает
  соединительные точки, не заменяя другие элементы скина.
- Скин → показ промахов слайдеров:
  **Нет** скрывает `sliderendmiss` и `slidertickmiss`;
  **50 и 100** заменяет их соответственно на `hit100` и `hit50` из скина;
  **По умолчанию** использует обычные элементы скина и нативные запасные изображения.
  Прежнее сохранённое выключение переносится в «Нет», включение — в «По умолчанию».
- Интерфейс → **Улучшенное изменение звука**: Alt + колесо обрабатывается до
  дочерних окон, поэтому работает из любой точки экрана, включая создание
  комнаты, комнату и наблюдение мультиплеера. Ctrl + Alt не перехватывается.

Новые настройки pp, шлейфа, SD и громкости по умолчанию выключены; существующие
предпочтения сохраняются. Подключение к официальному серверу не включает патчи SOMS!.

## Перемотка

Назначение клавиши: настройки клавиш → **Скины SOMS! → Тренировка — перемотка**.
По умолчанию сочетание не назначено, чтобы не пересекаться с игровыми клавишами.
Удерживание показывает полоску; щелчок или перетаскивание выбирает позицию.
Работает в одиночной игре и реплее, в мультиплеере недоступно.

После первого перемещения текущая попытка становится тренировочной: скор не
сохраняется локально и не отправляется на сервер. Обычный перезапуск карты
создаёт новую чистую попытку. Наличие назначенной клавиши само по себе ничего
не меняет в рейтинговой отправке.

Поведение шлейфа и удерживаемой перемотки изучено по исходникам McOsu:
[OsuHUD.cpp](https://github.com/McKay42/McOsu/blob/master/src/App/Osu/OsuHUD.cpp),
[Osu.cpp](https://github.com/McKay42/McOsu/blob/master/src/App/Osu/Osu.cpp),
[OsuOptionsMenu.cpp](https://github.com/McKay42/McOsu/blob/master/src/App/Osu/OsuOptionsMenu.cpp).

## Проверка и публикация

- 65 серверных тестов: уведомления, друзья, локальный Ranked, обработка и
  сохранность скоров. Повторно 11 тестов уведомлений после проверки JSON-модов
  на настоящем ORM-объекте из БД. Ruff и синтаксис JavaScript — без ошибок.
- Проверка на действующей БД: SOMSBot, единственный #announce, версия миграции,
  обработка реального объекта скора. Тестовое событие отменено откатом транзакции
  без публикации.
- Браузер Edge: колокольчик, чтение, ссылки, независимое сохранение предпочтений,
  мобильная ширина, безопасный вывод текста. Записи проверялись на изолированных
  ответах API, без уведомлений настоящим пользователям.
- Реальный OsuGame в отдельном профиле: настройки, Alt + колесо, шлейф,
  замены hit100/hit50, pp NM и DT 1.2, перемотка в обе стороны и запрет отправки,
  переходы меню → выбор → игра → результаты → повторная игра.
- 101 регистрация патчей остаётся уникальной после последовательных и
  параллельных инициализаций; проверены многократные замены скинов, очистка
  подписок и сохранение прежних настроек масштаба/горячих клавиш.
- Сервер пересобран, `app` перезапущен. Модуль опубликован штатным
  `switcher/stage-client-release.ps1`, оба лаунчера используют одинаковый SHA256.
- По localhost и `https://soms.angelfish-leaffish.ts.net` проверены новые ресурсы
  сайта, обязательная авторизация для уведомлений и SHA256 скачанного модуля.
