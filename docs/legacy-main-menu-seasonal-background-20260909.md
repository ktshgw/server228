# Локальный сезонный фон stable для Legacy interface

При проверке реальных снимков нового меню обнаружено, что огромные розовые кольца были частью старого встроенного `menu-background@2x.jpg`, а не аудиовизуализатором.

В установленном stable найден **тот же сезонный фон, что на пользовательских скриншотах**: зелёный и розовый маскоты в космосе. Источник — локальный кэш `C:\Users\Kts\AppData\Local\osu!\Data\bg\online_background_2affd9218824a206fbbdb15c63584362.jpg`. Несмотря на расширение `.jpg`, файл содержит PNG размером 2732 × 1536.

Исходный файл скопирован без изменения байтов в `.sources/LazerAuthlibInjection/osu.Game.Rulesets.EnhancedAuth/Resources/StableInterface/menu-background-seasonal@2x.png`. Размер — 4 643 034 байта. SHA-256: `278347dc37a7a60b94369c5972d64969cdfd1627b65b33cab48c32ac19435e5e`.

Авторская подпись в правом нижнем углу изображения сохранена. Файл используется как встроенный запасной фон меню; собственный `menu-background` выбранного скина имеет приоритет. Это зафиксированный ресурс из локальной установки, а не подписка на сезонные обновления официального сервера.

Радиальный спектр — отдельный штатный `MenuLogoVisualisation`, дочерний элемент логотипа. Он получает частотные амплитуды настоящего `IBeatSyncProvider` и перемещается вместе с логотипом. На тестовой карте с тишиной полосок спектра нет; искусственные амплитуды не подставляются.
