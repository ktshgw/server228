# Шрифт Legacy interface

Источники проверены 2026-09-09: `Aller.ttf` и `Aller_Bd.ttf`, извлечённые из
локального `osu!ui.dll`. Исходные размеры — 134 436 и 128 368 байт.
Проверка cmap через fontTools показала: оба начертания содержат весь базовый
латинский алфавит, но **ни одного символа диапазона U+0400–U+04FF**.

Для Legacy interface создана отдельная семья `SomsAller` с Regular и Bold.
Латиница берётся из настоящего Aller. Кириллица и отсутствующие знаки взяты явно
из `C:\Windows\Fonts\arial.ttf` / `arialbd.ttf`, чтобы русский текст не переходил
на округлый Torus. Это выбранная реализация кириллического fallback; её не следует
называть найденным исходным шрифтом кириллицы stable.

`scripts/build-stable-interface-fonts.py` использует уже установленные Pillow и
fontTools. Генератор читает TTF, проверяет coverage и пишет стандартные **BMFont v3**
и PNG-атласы, которые загружает штатный GlyphStore osu!framework. Во время игры TTF
не нужны, установки системного шрифта нет. Пакет находится отдельно в
`Resources/StableFonts`, набор 125 исходных изображений интерфейса не меняется.

Параметры соответствуют соглашению штатного `Roboto-Regular.bin`: размер 100,
базовая линия 80, атласы 1024×1024. Глифы двух исходных шрифтов выровнены по
базовой линии. Сохранены advance, offsets и доступные кернинговые пары TTF.

| Начертание | Глифы Aller | Явный fallback | Страницы | Кернинг | Байты |
| --- | ---: | ---: | ---: | ---: | ---: |
| Regular | 335 | 262 | 4 | 1127 | 506 161 |
| Bold | 335 | 262 | 4 | 1112 | 488 512 |

Поддерживаются Basic Latin, Latin-1/Extended-A, кириллица и общие знаки интерфейса.
Отсутствующие в обоих источниках символы не подменяются квадратиком: для них остаётся
обычный fallback клиента, в том числе Noto для CJK. Manifest содержит SHA-256 TTF,
атласов и бинарных метрик, точные списки исходных/fallback-глифов и версию Pillow.

API для экранов: `SomsLegacyFont.Font(float size, bool bold = false)`.
Базовый Legacy-компонент регистрирует два `TimedExpiryGlyphStore` в FontStore один
раз для соответствующего game host. Только текст с явным использованием этой
семьи получает новый шрифт. Имена Torus/Inter/Roboto и нативные настройки не меняются.
Регистрация хранится в ConditionalWeakTable; временем жизни атласов и глифов
управляет штатный font store.
