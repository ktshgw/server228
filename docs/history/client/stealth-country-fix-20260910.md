# Stealth: страна и национальный ранг — 10.09.2026

Клиент: osu!lazer 2026.804.2, osu.Framework 2026.731.0. Сборка `SomsStealthCountryFix2`.

## Изменения

- API подбора возвращает страну и национальный ранг официального игрока. Обновление ранга принимает `country` выбранной личности и ищет позицию по текущим PP в рейтинге этой страны; личность при этом не меняется.
- Обработаны границы страниц, одинаковые PP и ответы без поля `country_rank`. Кэш официальных страниц сохраняется; исходные ответы не изменяются.
- Клиент показывает национальный ранг в карточке пользователя и шапке профиля. Если начальный ответ не содержит ранга, клиент отдельно запрашивает страну через 2,1 секунды без реролла.
- Флаги привязаны к пользователю, а не к исходному коду страны. Подмена применяется к собственным карточкам, профилю, игровому флагу, строкам результатов и участникам комнаты. Чужой игрок с той же исходной страной сохраняет свой флаг.
- Название страны и переход к её рейтингу в шапке профиля соответствуют подмене. Отключение Stealth восстанавливает исходные значения. Модель аккаунта, ID, статистика в кэше и передаваемые результаты остаются исходными.
- При выходе за доступные 10 000 позиций национального рейтинга результат отмечается как приблизительный; в подробностях профиля это указано в подсказке.
