# Клиентский аудит и раздельный масштаб — 8 сентября 2026

Проверено на установленном lazer **2026.804.2**, .NET **8.0.29**,
osu.Framework **2026.731.0**. Публичный пакет для компиляции —
ppy.osu.Game **2026.730.0**. Значения enum настроек между версиями могут
отличаться: ключи native config нужно разрешать по имени, а не сохранять
числовую константу из пакета компиляции.

## Изменения

- Скрытие `sliderendmiss` и `sliderfollowcircle` проверяется при обновлении
  `SkinnableDrawable`, а также после смены скина. Это закрывает сброс Alpha
  между событиями смены скина и позднее подключение патча к уже загруженным
  объектам. Нативные дети, анимации и прокси не заменяются; подписки
  освобождаются при уничтожении объекта. Точную последовательность действий
  на компьютере друга воспроизвести по одному описанию нельзя.
- В графических настройках после общего масштаба добавлен переключатель
  «Расширенное масштабирование интерфейса» и два ползунка: меню и игра,
  каждый от 0,1× до 2×. По умолчанию расширенный режим выключен, оба значения
  равны 1×. Настройки хранятся в `soms_client_preferences.json`.
- Игровой масштаб выбирается по активному экрану `Player`, включая реплеи,
  паузу и перерывы. Координаты игрового поля и размер объектов сохраняются.
  При отключении расширенного режима действует исходный общий масштаб.
- Для загрузчика карт SOMSAI ключ `PreferNoVideo` разрешается по имени.
- Последние результаты на главной открывают существующий диалог
  подробностей скора. Порядок показателей профиля: медали, PP, MMR SOMSAI,
  время в игре. Версия веб-ресурсов увеличена до 25.
- `client/switcher/stage-client-release.ps1` по умолчанию берёт путь из актуального
  shared-launcher config; больше нет возврата к старому `bin/SomsClientRelease`.
  Обновляются контрольные суммы обоих форматов конфигурации лаунчера.

## Проверки

- `Preferences.Lifecycle.Check`: по 30 циклов настроек, скинов и освобождения
  ресурсов; сброс Alpha без SkinChanged; позднее подключение; восстановление
  штатного режима; реальные расчёты Scale/Size на 0,1 и 2; независимость меню
  и Player; сохранение настроек. Проверка сброса Alpha падала на предыдущем
  опубликованном модуле и проходит на исправленном.
- `FullPatchLifecycle.Check`: 11 групп, включая однократную установку всех
  патчей и параллельные конструкторы.
- `RankedMods.Check`: 96 комбинаций; сохранение и конфликты горячих клавиш
  в отдельной Realm. Учтён существующий шестой подраздел таблицы рекордов.
- `ReplayAvatar.Check`: 18 проверок идентификации и аватарок реплеев.
- `Multiplayer.Check`: 37 проверок личных DT/NC и синхронизации времени.
- `SomsAi.Client.Check`: отрисовка форматов/драфта/пати, 100 обновлений без
  дублирования, отмена запросов, восемь изолированных профилей, заблокированный
  обычный Ranked. Тест пересобран из текущего исходника.
- `LegacyInterface.Check`: нативные действия экранов, режимы результатов,
  недостающие элементы скина, узкий экран, 30 смен скина/режима, освобождение.
- `LegacyScreens.Integration`: настоящий OsuGame с отдельным профилем и Dummy
  API: меню → выбор карты → моды → реплей → результат → повтор → результат.
  Проверены масштабы меню/игры и восстановление общего масштаба.
- Headless Edge на исходниках и затем на публичном сайте: клик мышью,
  Enter, ширина 390 px, порядок показателей; ошибок JavaScript нет.

Сетевые матчи с реальными игроками эти клиентские проверки не имитируют.
Пользовательская Realm и реальные игровые настройки при тестах не менялись.
