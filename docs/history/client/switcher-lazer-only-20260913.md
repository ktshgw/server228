# Свитчер 1.1.2: запуск SOMS при открытом stable

Кнопка «Официальный Bancho» и её обработчик удалены. Кнопка «Играть на SOMS!»
занимает освободившееся место. Сообщения об отсутствии сервера и неподдерживаемой
версии больше не предлагают удалённую функцию.

Раньше любой процесс с именем `osu!` блокировал запуск. Stable и lazer используют
одно имя, поэтому эта проверка отклоняла и открытый stable. Новый общий
`client/launcher/LazerProcessGuard.cs` получает путь процесса через ограниченный
QueryFullProcessImageName и определяет lazer по ProductName/FileDescription.
Для переносимых сборок используется наличие osu.Game.dll, osu.Framework.dll
и конфигурации .NET рядом с EXE. Повторный запуск lazer остаётся заблокированным.
Выбор EXE stable вместо lazer также показывает понятную ошибку.

Тот же код подключён к обоим PowerShell-лаунчерам. Клиенты не закрываются,
настройки и файлы установленных stable/lazer не меняются.

Проверки: 14 проверок собранного EXE, включая два реально открытых клиента
(stable исключён, lazer включён), переносимую установку, интерфейс и запрет
повторного запуска lazer. Выполнены 12 существующих проверок launcher и отдельный
прогон общей проверки из PowerShell. Игры для проверки не запускались и не закрывались.

Артефакт: `.test-tmp/switcher-lazer-only/build/SOMS-switcher.exe`,
версия 1.1.2.0, 212 992 байт,
SHA256 `6e7cad5a658ec8831d5501a33225987fd6a9033755b14aab4efed2f5eb10a719`.
Резервные копии и логи: `.test-tmp/switcher-lazer-only/`.

Обновление самой программы: скачать `/client/SOMS-switcher.exe?v=1.1.2`,
закрыть старый свитчер и заменить EXE. Кнопка «Обновить» обновляет сведения
о сервере, а не сам свитчер. Старый адрес `/client/soms-switcher.exe` также
отдаёт новую версию.
