# Legacy: миниатюры и переходы между мапсетами

Модуль `SomsLegacyCoversFinal`, osu!lazer 2026.804.2.
SHA-256: `a35e7d4536e1902382f318b1fedeae4f9ef5a3cbe20fae8c99503e976d927d3a`.

## Исправление

В `SomsLegacySongSelect.LegacyMapRow` загрузка миниатюры была ошибочно ограничена
условием `map.BeatmapSet.Files.Count > 0`. Штатная карусель использует detached
снимки, в которых Files специально отсутствуют. Поэтому существующие фоны не
передавались загрузчику, и на экране оставался цветной квадрат.

Теперь строка создаёт отложенный `LegacyMapCover`, а его асинхронный загрузчик
вызывает `BeatmapManager.GetWorkingBeatmap(map).GetBackground()`. Менеджер сам
восстанавливает файлы из Realm; используется общий кэш изображений lazer.
`GetPanelBackground()` не подходит для этих миниатюр: он обрезает фон в узкую
горизонтальную полосу для штатных панелей. Размер видимой миниатюры остаётся
69×51, изображение заполняет рамку с сохранением пропорций.

←/→ вызывают `moveSet`, пропуская все сложности с ID текущего набора и выбирая
соседний мапсет в порядке списка. Переход циклический; при единственном мапсете
выбор не меняется. ↑/↓ сохраняют переход по отдельным сложностям. Прокрутка
мышью остаётся независимой от выбранной карты.

## Проверка и доставка

Фикстура интеграции теперь импортирует три мапсета по 18 сложностей с настоящим
PNG-фоном 64×48. Проверка подтверждает отсутствие Files в снимках карусели и
наличие загруженной текстуры нужного размера во всех полностью видимых строках.
Реальный ввод проверяет переход вправо в соседний мапсет, возврат влево и
сохранение перехода по сложностям для ↑/↓. Полный цикл игры, Retry, F1/F3,
Shift+F2, колесо, drag и Alt+колесо прошёл.
