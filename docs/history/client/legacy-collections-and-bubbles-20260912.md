# Legacy: коллекции, ПКМ и переход SOMSAI — 12.09.2026

Модуль `SomsCollectionsBubblesRelease` для osu!lazer 2026.804.2 опубликован. Размер 17 090 560 байт, SHA256 `ebc9256f97e90fa7e90f9e8ea1fa1d1356efbc0222fc89d3bb436fef5e44f3b3`.

## Изменения клиента

- ПКМ по строке карты выбирает её и открывает те же действия, что F3. В текущем framework событие ClickEvent для ПКМ не генерируется, поэтому клик определяется по нажатию/отпусканию с учётом перемещения и перетаскивания. Быстрая прокрутка начинается при движении с зажатой ПКМ; простое нажатие больше не перемещает список.
- Первая кнопка меню F3 открывает собственное окно коллекций Legacy. Доступны создание, переименование, выбор и удаление коллекции с повторным подтверждением. `+` / `−` меняют только выбранную сложность; `+Set` / `−Set` — весь установленный мапсет. Полный набор сложностей перечитывается из Realm и не ограничен текущими результатами поиска. Повторные добавления не создают дубликаты. Изменения сохраняются в штатных BeatmapCollection и сразу доступны в группировке «Коллекции».
- «Улучшенное изменение звука» перенесено из интерфейса в настройки звука сразу после выбора устройства вывода, перед Legacy Audio. Сохранён прежний параметр, его значение и обработка Alt + колесо.
- Вход в SOMSAI из главного меню запускает отдельный слой с 104 анимированными пузырьками. Он закрывает предыдущий экран, переключает экран под непрозрачным слоем воды, ждёт готовности назначения и поднимает пузырьки вверх. Слой блокирует повторные нажатия и освобождается после перехода. Количество объектов фиксировано, новые изображения по сети не загружаются.
