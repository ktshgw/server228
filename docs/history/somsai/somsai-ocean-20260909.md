# SOMSAI: подводный интерфейс

Опубликованный модуль: `SomsAiOceanRelease`, osu!lazer 2026.804.2.
SHA-256: `32f21aa00fe268b08f8cbcbbdaed56d786db5b31ad8a2e8693c3d3e22572af81`.

## Оформление

Согласованный макет перенесён в действующий интерфейс SOMSAI: главный экран,
пати и приглашения, форма кастома, список комнат, поиск, выбор пула для старых
матчей, ожидание участников, баны и пики, готовность, результаты и подтверждение
выхода. Бирюзовые панели, кремовые заголовки с ракушками и золотые основные
кнопки используют общие компоненты. Данные игроков, рейтинг, список карт и
все действия по-прежнему берутся из действующего состояния матча.

В ресурсы DLL включены отдельные иллюстрация фона и прозрачный логотип.
Фон содержит сома в сомбреро и рыбу-шар из принятого оформления. Поверх него
двигаются 20 пузырьков и 5 полупрозрачных лучей; изображение также плавно
смещается на несколько пикселей. Количество объектов фиксировано. При уходе
с экрана анимация останавливается, а содержимое SOMSAI скрывается. Появление
экрана, раскрытие форм и наведение на кнопки анимированы.

При небольшой ширине две колонки превращаются в одну; длинные формы и пул
доступны через вертикальную прокрутку. Текст результатов переносится по строкам.
Оформление локально для экранов SOMSAI; игровой процесс использует штатный
мультиплеерный механизм lazer.

## Проверки и доставка

Сборки модуля и проверок прошли с 0 ошибками и 0 предупреждениями.
Графический прогон проверяет загрузку ресурсов, ширины 1280 и 640, 15 карточек
с отдельными превью, отмену асинхронного превью, формы, поиск, результат,
остановку фоновой анимации после переключения экрана и отмену подтверждения.
Отдельная проверка действий подтверждает приглашения, вход в обе команды,
права на баны/пики, защиту от повторного действия, готовность, повторный поиск
и отображение изменения MMR. Проверка использует фикстуры, без живого матча
между аккаунтами и без изменения серверного рейтинга.

Логи: `.test-tmp/somsai-ocean-delivery-visual.log` и
`.test-tmp/somsai-ocean-delivery-actions.log`.

Установленный runtime использует немаскируемый `PopupDialog.Content`.
Декорация диалога поэтому применяется только к фактическим маскируемым
контейнерам; это проверено рендером и отменой диалога.

Выпуск опубликован через `client/switcher/stage-client-release.ps1`. Проверены оба
пина лаунчеров, публичный манифест и хеш повторно скачанного DLL.
Предыдущий модуль сохранён в `.test-tmp/somsai-ocean-release/previous.dll`
(SHA-256 `2891b3f7da89e5754fe6b93fda3741748c581f453edc1b91f6099ba10b804c2a`).
