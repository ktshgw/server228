# Приватный запуск с общей библиотекой

Используется обычный подписанный `osu!.exe` и существующая папка `D:\lazer`.
Копии клиента, копии карт, hardlink, symlink и DLL в `D:\lazer\rulesets` не нужны.

Запускать нужно файл `PLAY_PRIVATE_OSU.bat` в корне проекта. Он:

1. при необходимости запускает Docker-сервер;
2. проверяет подпись и поддерживаемую версию официального lazer;
3. только для дочернего процесса подключает внешний startup hook;
4. запускает обычный установленный lazer с приватными API endpoints.

Обычный ярлык osu! продолжает запускать официальный сервер. Нельзя держать
официальный и приватный клиент открытыми одновременно.

Карты, скины, настройки и `client.realm` общие и остаются в `D:\lazer`.
Приватные `Username` и `Token` не записываются вместо официальных: они хранятся
отдельно в Windows Credential Manager. В приватном запуске нельзя вводить пароль
от официального osu! — используется отдельный аккаунт этого сервера.

При обновлении официального lazer launcher безопасно остановится, если версия ещё
не проверена. Обновлять сервер целиком обычно не требуется, но модуль надо будет
пересобрать и протестировать с новой версией клиента.

## Legacy interface

В приватном клиенте: **Настройки → Скин → Legacy interface**. По умолчанию выключено;
настройка общая для скинов и сохраняется в `soms_client_preferences.json` выбранного профиля.
Она применяется без перезапуска и обновляет оформление при смене скина.

Переключатель включает экспериментальные сцены, воспроизводящие части интерфейса stable:

- Главное меню с кругом, вложенными меню игры/редактора/мультиплеера и доступом к аккаунту.
- Выбор карт со своим списком, поиском, сортировкой, группами, рекордами и нижними кнопками.
  Стрелки и колесо меняют выбор; Enter запускает карту; F1/F2/F3 открывают моды,
  случайный выбор и настройки карты. В настройках карты можно сбросить скрытые фильтры.
- Результаты с информацией карты и игрока, счётом, попаданиями, комбо, точностью,
  рангом и кнопками повтора/повторной игры. Значения берутся из настоящего скора.
- Сетка модов, экраны паузы/поражения и компактный браузер комнат.

Используются `menu-background`, `menu-osu`, `menu-button-play/edit/options/exit`,
`menu-button-freeplay/multiplayer/back`, `menu-osudirect` (старые псевдонимы `menu-logo`,
`menu-play/edit/options/exit/solo/multi/direct` также поддерживаются),
`menu-button-background`, `menu-back`, `selection-*`, `selection-mod-*`, `ranking-*`,
цифры шрифта счёта, изображения попаданий и `pause-overlay`, `fail-background`,
`pause-continue/retry/back/replay`. Варианты `@2x` разрешает штатный загрузчик;
поддерживаются покадровые изображения и состояния `-over` у кнопок меню.
Прозрачные изображения 1×1 учитываются как намеренно скрытые элементы скина.
Собственные элементы интерфейса используются только при отсутствии картинки.

На заменённых экранах скрыты панель и футер lazer. Нативные компоненты продолжают
обрабатывать выбор, загрузки и сетевые действия, но не перехватывают ввод.
Отключение возвращает исходные компоненты; файлы скина и карты не переписываются.

Редакторы, SOMSAI-матч, общие настройки, подробная статистика и расширенные параметры
модов пока используют соответствующие экраны lazer. Они доступны из классического
меню. Переключатель не меняет правила игры, моды, подсчёт очков или серверный рейтинг.

Это не загруженный движок stable и не полная копия всех его экранов. Встроенный
Legacy-набор lazer содержит лишь часть ресурсов stable; меню без соответствующих
картинок в пользовательском скине по-прежнему используют запасное оформление.
Исследование установленного stable и выявленные расхождения описаны в
[`docs/legacy-interface-stable-audit.md`](../docs/legacy-interface-stable-audit.md).
