САЙТ PRIVATE OSU! — КОРОТКАЯ ПАМЯТКА

1. Запусти START_SERVER.bat и дождись Done.
2. Запусти OPEN_WEBSITE.bat — откроется обычный сайт сервера.
3. Там можно зарегистрироваться или войти, смотреть профили, PP, рейтинги,
   лучшие/последние score, искать и скачивать карты, менять страну и аватар.
4. Админ-панель по-прежнему открывается через OPEN_ADMIN_PANEL.bat.

Если у старого аккаунта стоит китайский флаг: сайт → Настройки → Страна →
выбрать нужную страну → Сохранить профиль. Скорее всего, страна была определена
по IP включённого VPN при первой регистрации.

СМЕНА НИКА

Админ-панель → Пользователи → выбрать игрока → Имя пользователя → указать
причину → Сохранить. Действие записывается в историю.

ПЕРЕНОС SCORE

Админ-панель → Импорт score → вставить публичную ссылку вида
https://osu.ppy.sh/scores/... → указать ID локального игрока → Проверить →
Импортировать. Сервер сам получает данные с официального osu! и проверяет по
replay, на какой версии карты был сыгран результат. Если версия подтверждена,
сервер считает PP своей обычной формулой и добавляет score в лидерборд. Если
подтверждения нет, score по умолчанию будет виден в профиле, но останется без PP
и вне лидерборда.

Флажок «Принудительно дать рейтинг и PP без подтверждения ревизии» — рискованный
режим только для владельца. Включай его лишь если точно принимаешь возможность
неверного PP на старой версии карты. Импортированный результат и это решение
помечаются на сайте и навсегда записываются в журнал администратора.

Аккаунты и score лежат в MySQL-томе Docker server_mysql_data. Обычный Stop и
перезапуск компьютера их не удаляют. Никогда не запускай docker compose down -v
и не удаляй этот Docker volume, если не хочешь стереть базу.
