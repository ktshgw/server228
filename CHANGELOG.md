# SOMS! 25.9.26b1

Released 25 September 2026.

## Added

- Added an update history page and a changelog menu to the SOMS! website.
- A fallback mechanism has been added, allowing ARCHSOM players with an MMR above 3500 to find matches in situations that were previously impossible.

- Fixed Double Time BPM being multiplied twice for maps selected from the SOMSAI mappools.
- Fixed unprocessed multiplayer scores being displayed as `0pp` for other players.
- (Admin) Made the SOMSAI mappools refresh fully rebuild and compare every map, including modded stats and rank eligibility.

## Changed

- The website home page now shows the latest server update instead of the Local Ranked promotion card.

## Removed

- Removed the recent results section from the website home page.
