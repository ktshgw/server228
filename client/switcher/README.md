# SOMS! switcher

`SOMS-switcher.exe` запускает установленный официальный osu!lazer на
`SOMS!`. Карты, скины, настройки и выбранная в
`storage.ini` папка остаются общими. В папку osu! DLL не копируются.

При приватном запуске программа:

1. определяет версию официального `osu!.exe`;
2. получает `/client/manifest.json` только по HTTPS;
3. скачивает совместимые DLL в `%LOCALAPPDATA%\SOMS-switcher\modules`;
4. проверяет размер и SHA-256 каждой DLL;
5. подключает их только к дочернему процессу через `DOTNET_STARTUP_HOOKS`.

Приватный логин хранится отдельно от официального в Windows Credential
Manager. Обычный ярлык osu! не меняется.

С версии 1.1.2 кнопка запуска Bancho убрана. Открытый osu!stable не мешает
запуску SOMS: общий `client/launcher/LazerProcessGuard.cs` различает stable и lazer
по метаданным EXE и файлам клиента, а не только по имени процесса `osu!`.
Повторный запуск уже открытого lazer по-прежнему блокируется. Та же проверка
используется в PowerShell-лаунчерах и `PLAY_PRIVATE_OSU.bat`.

## Сборка и публикация

```powershell
powershell -ExecutionPolicy Bypass -File .\client\switcher\build-switcher.ps1
powershell -ExecutionPolicy Bypass -File .\client\switcher\stage-client-release.ps1
```

Готовый файл находится в `client\switcher\dist\SOMS-switcher.exe` и публикуется по
адресу `/client/SOMS-switcher.exe`. Старая ссылка на скачивание и ранее выбранный
путь к osu! продолжают работать. После добавления
новой совместимой версии достаточно положить две проверенные DLL в
`static\client\<версия>`. Пересобирать сам свитчер не требуется.

С версии 1.1.1 лимит модуля составляет 64 МиБ (раньше 16 МиБ). Старый свитчер
отклоняет текущий модуль с ресурсами меню: 17 061 888 байт. Пользователям версии
1.1.0 нужно скачать новый EXE по той же ссылке. Кнопка «Обновить» обновляет
сведения о сервере, а не сам EXE. Публикация проверяет размер DLL относительно
лимита собранного свитчера до замены файлов.

Для обновления самого свитчера скачайте `/client/SOMS-switcher.exe?v=1.1.2`
и замените старый EXE. Кнопка «Обновить» внутри старой программы её не заменит.

Свитчер намеренно не запускает Docker: сервером управляет только владелец.
Друзья подключаются к публичному Tailscale Funnel; устанавливать Tailscale им не нужно.
